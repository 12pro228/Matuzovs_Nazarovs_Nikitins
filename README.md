# Virtuālā izstāde – tīmekļa vietnes izstrādes projekts

## 1. Projekta apraksts
Projekts ir izstrādāts prakses laikā, izmantojot HTML5, CSS3 un JavaScript. Projekta mērķis ir izveidot interaktīvu un responsīvu tīmekļa vietni — virtuālu izstādi par izvēlēto tēmu.

- **Izstādes tēma:** Automobiļu vēsture un dizains
- **Izstādes nosaukums:** SILUETS — Ātruma forma

## 2. Komandas dalībnieki
1. Vārds Nikitins
2. Vārds Nazarovs
3. Vārds Matuzovs

## 3. GitHub repozitorijs
Projekta pirmkods un izstrādes vēsture ir pieejama GitHub repozitorijā:
- **GitHub Repository:** https://github.com/12pro228/Matuzovs_Nazarovs_Nikitins

## 4. Izmantotās tehnoloģijas
- **HTML5** — tīmekļa vietnes semantiskās struktūras, navigācijas un 3D skata dialoga loga izveidei.
- **CSS3** — tīmekļa vietnes dizainam, Box Model, Flexbox/Grid un responsīvajam izkārtojumam.
- **JavaScript** — attēlu kolekcijas ģenerēšanai, interaktīva karuseļa un 3D skata darbībai.
- **GitHub** — projekta failu versiju kontrolei un komandas sadarbībai.

## 5. Tīmekļa vietnes funkcionalitāte
Izstrādātajā tīmekļa vietnē ir:
- Galvene un navigācijas izvēlne ar enkura saitēm.
- Izstādes apraksts.
- Attēlu galerija (8 automobiļi ar 3D apskates režīmu).
- Interaktīvs attēlu karuselis ar manuālu un automātisku pārslēgšanu.
- Responsīvs dizains dažādām ierīcēm.
- Lapas kājene ar informāciju par projekta autoriem.

## 6. Projekta palaišana
1. Lejupielādējiet projekta failus vai klonējiet GitHub repozitoriju.
2. Atveriet projekta mapi.
3. Atveriet failu `index.html` tīmekļa pārlūkprogrammā.
4. Pārbaudiet tīmekļa vietnes funkcionalitāti.

## 7. Projekta izstrādes ieguldījums
- **Nikitins:** HTML5 struktūra, semantiskie elementi, navigācija un 3D dialoga loga izkārtojums (`index.html`).
- **Nazarovs:** CSS3 dizains, Flexbox/Grid izkārtojums un responsīvais pielāgojums (`css/style.css`).
- **Matuzovs:** Automobiļu datu kolekcija, attēlu galerijas un karuseļa JavaScript loģika (`js/collection.js`, `js/gallery.js`).
